# Gauchito Gil 2027 · Gestión Premium

Web online para gestionar pasajeros, confirmaciones, pagos, cabañas y presupuesto del viaje al Gauchito Gil.

## Funciones

- Firebase Firestore en tiempo real.
- Vista pública en modo consulta.
- Edición protegida mediante Firebase Authentication.
- Alta y baja de pasajeros en tiempo real.
- Presupuesto dinámico según cantidad de pasajeros.
- Transporte original: $5.800.000.
- Bonificación delegados: $1.000.000.
- Dos choferes sin cargo.
- Cabañas de 5 personas a $280.000 cada una.
- Distribución automática de cabañas.
- Cálculo de total por pasajero, pagos y saldo.
- Exportación CSV e impresión/PDF.

## Firebase

Proyecto: `gauchito-gil-pasajeros`.

Para que el login funcione desde GitHub Pages, agregar `comercio-3212.github.io` en Firebase Authentication > Configuración > Dominios autorizados.
